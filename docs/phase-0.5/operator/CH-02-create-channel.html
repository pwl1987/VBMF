Switch Mode (PACKET/FRAME/MASTER) 由 Compiler Decision Tree 决定; 此处只选"发生故障后是否允许系统自动执行已编译决策". 切换判据 (信号丢失阈值/静帧检测) 在 D5/E-40 定义 (0.5F.3 P1-6 修正).
Program Master = GraphRuntime Compiler 的结果 (DESIRED→COMPILED→EFFECTIVE), 不是创建向导选择的"输出模式". PVW/PGM (Monitoring/Switching) 在 CD-01 Workspace 表达 (0.5F.3 P1-5 修正).
