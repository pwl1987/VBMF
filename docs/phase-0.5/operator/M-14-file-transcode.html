▸ Step 3 Profile (Encoding / Packaging / Job Policy — 职责分离)
⚑ 0.5F.14 · FILE_TRANSCODE 对象链 (本页 M-14)：本步为目标资产版本 (Target Asset Version) 选 Packaging Profile——这是资产版本级的 Packaging（产物为单文件/自适应包，归属该 Asset Version），不是 Channel 的 Output Variant 级 `packaging_profile_ref`。两者共享 Packaging Profile Registry，但对象上下文不同（Asset Version ≠ Output Variant）。选择项旁可展开 FILE compatible / DELIVERY compatible 标记与 Inherited / Overridden / Explicit / Compiled / Effective 来源链（OBJECT_VOCABULARY §1.16）。
① Encoding Profile (P-21 · FILE_PROFILE)
只含编码语义: Codec / Resolution / FPS / Bitrate / GOP / Audio Encode / Quality (CRF / 1-2 pass)。⛔ 不承担 Container / Segment / Manifest / DRM（归 Packaging）。
② Packaging Profile (P-20 · PACKAGING_PROFILE) — 显式选择
Delivery Packaging: Container / Segment / Manifest / DRM。⛔ 不承担 codec / resolution / bitrate / GOP（属 Encoding）。
③ Job Policy (Step 5 调度 · 与 Profile 解耦)
Worker / Concurrency / Priority / Retry / Schedule / Storage 属 Job 运行时策略，不混进 Encoding / Packaging Profile (EXECUTION_MODEL §2)。
职责边界 (0.5F.12 焊死): ① Encoding Profile (P-21 · FILE_PROFILE): Codec / Resolution / FPS / Bitrate / GOP / Audio Encode / Quality。不含 Container / Segment / Manifest / DRM。 ② Packaging Profile (P-20 · PACKAGING_PROFILE): Container / Segment / Manifest / DRM。不含 codec / resolution / bitrate。 ③ Job Policy: Worker / Concurrency / Priority / Retry / Schedule / Storage。 本 picker 只显示 FILE_PROFILE 分支（严格禁止 REALTIME_PROFILE，那是 M-17 / Session 的 ENCODE_MODEL_SPEC §3）。
