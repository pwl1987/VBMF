⑥ 风险评级 (4 级 · 算法)

等级触发条件阻断
✓ LOW0 Channels ON_AIR + 0 Sessions不阻断
⚠ MEDIUM1-2 Channels ON_AIR / 1-5 Sessions不阻断, 提示 schedule
⚠⚠ HIGH3+ Channels / 6+ Sessions阻断直接 Apply, 必须走 ChangeSet
⛔ CRITICAL任一 LIVE EVENT / 任一 Bundle 修改强制 Schedule 或人工审批
算法: `live_events or bundle_change → CRITICAL; ≥3 on_air or ≥6 sessions → HIGH; ≥1 on_air or ≥1 session → MEDIUM; else LOW`。
