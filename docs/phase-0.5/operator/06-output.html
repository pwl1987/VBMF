Recommended Actions 推荐恢复路径 (按序)

  1. Restart HLS Adapter — 重启故障适配器, 不影响节目源 (L2)
  2. Retry — 重试写入 CDN, 适用瞬时错误
  3. Fallback Output Variant — 切换到备用 HLS 变体 / 备份 CDN (不切节目源)
⛔ 禁止: 此故障不应触发 Source/Program FAILOVER — 错误恢复路径为「输出适配器级」而非「信号源级」(Failure Domain Matrix §8.9)。

边界 (0.5D.1 焊死): Output Resilience ≠ Failure Recovery. Resilience 回答"输出自己怎么自愈" (retry / backoff / heartbeat / zombie); Failure Domain 回答"自愈失败后系统下一步怎么办" (Fallback destination / Alert)。retry 全失败只降级 + 告警, 绝不切节目源。
