Network UDP · RTP · SRT · RTMP · HLS · WebRTC Pull · RTSP — 本页演示 Network → UDP
Physical (SDI) / File / Internal (BLACK·BARS·FILLER) 为其他 Kind 分支。Kind 决定 Transport; Transport(UDP) 再决定 Delivery Mode (UNICAST / MULTICAST_ASM / MULTICAST_SSM), 三者 Endpoint Schema 不同 — 不是平铺大表单。选择 Delivery Mode 后仅渲染对应 Endpoint Schema, 其余自动隐藏 (原型默认 SSM).
