WorkFlow #1 创建新频道

1. Operator 选 "Create Channel"
2. 选 Bundle (新建 / 复用现有)
3. 选 Source (1..N, 冗余配置)
4. 选 Output Variant (1..N)
5. Preflight (E-32)
6. 提交 ChangeSet (DRAFT → VALIDATED → SCHEDULED → APPLYING → APPLIED)
7. Channel 进入 STARTING → READY_TO_TAKE

WorkFlow #2 升级一个 Profile (影响多个 Bundle)

1. Engineer 改 H264-LIVE-1080P25-5M (创建新 Revision v4)
2. Impact Preview: 2 个 Bundle (CH01-News / CH03-Sports) 引用 v3 → 将升级到 v4
3. 选 Channel 子集 (e.g. 1 个 Channel 先升, 1 个稍后)
4. 创建 ChangeSet (含 2 个 ChangeSetItem: 2 个 Bundle 升级)
5. 选 Schedule (立即 / 凌晨 02:00 / 下次维护窗口)
6. 走 Logical Atomic Apply

WorkFlow #3 / #4 临时 Override · 改 Channel Output Profile

Override (L2): Operator 进 CD-01 → "临时 Override" (L2) → 选临时 Profile → 填 Who/Why/Until → 立即生效 (不进 ChangeSet, 进 Audit) → Until 到期回滚.
改 Channel (Workflow #3): Operator 进 CD-01 → 改 Bundle 引用 v2→v3 → Impact Preview (3 个 Variant) → ChangeSet → 立即应用 → Variant 重派生.
