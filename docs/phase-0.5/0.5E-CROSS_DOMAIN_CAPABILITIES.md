## 1.4 风险评级 (4 级 · 算法)

| 等级 | 触发条件 | UI 表现 | 阻断 |
|---|---|---|---|
| **LOW** | 0 Channels ON_AIR + 0 Sessions RUNNING | 绿色 ✓ "Safe to apply now" | 不阻断 |
| **MEDIUM** | 1-2 Channels ON_AIR 或 1-5 Sessions | 黄色 ⚠ "Schedule at next boundary" | 不阻断, 提示 |
| **HIGH** | 3+ Channels ON_AIR 或 6+ Sessions | 橙色 ⚠⚠ "Requires ChangeSet" | 阻断直接 Apply, 必须走 ChangeSet |
| **CRITICAL** | 任一 Channel 处于 LIVE EVENT 状态 / 任一 Bundle 修改 | 红色 ⛔ "Do not apply during live event" | 强制 Schedule 或人工审批 |

**算法** (伪代码):

```python
def compute_risk(impact):
    active_channels = [c for c in impact.channels if c.on_air]
    active_sessions = [s for s in impact.sessions if s.running]
    live_events = [c for c in impact.channels if c.in_live_event]

    if live_events or impact.bundle_change:
        return "CRITICAL"
    if len(active_channels) >= 3 or len(active_sessions) >= 6:
        return "HIGH"
    if len(active_channels) >= 1 or len(active_sessions) >= 1:
        return "MEDIUM"
    return "LOW"
```

⛔ **15 canonical = 14 diffable + 1 revision meta (0.5F F2):** Revision 是不可变快照, 自身就是 diff 的基线, 不需要 Diff 自身 (Diff 目标是 Revision 对, 不是对象体)。

## 2.3 Diff 视图 (3 种)

| 视图 | 适用 | 优势 | 劣势 |
|---|---|---|---|
| **Side-by-side** | 字段数 ≤ 30 | 一眼对比 | 占空间 |
| **Inline (Unified)** | 字段数 > 30 或大文本 | 紧凑 | 对比慢 |
| **Multi-row** | Bundle / Channel 等复合对象 | 跨 N 对象 | 复杂 |

⛔ **禁止把 Side-by-side 用于字段 > 30 的对象** (Bundle / Channel 必用 Multi-row)。

## 2.4 Diff 字段分类 (3 类)

| 分类 | 含义 | UI 颜色 | 阻断 |
|---|---|---|---|
| **Value Change** | 同一字段值不同 (e.g., bitrate 5000→5500) | 黄色背景 | 通常不阻断 |
| **Structure Change** | 字段新增/删除/类型变 | 红色边框 | **必阻断 Apply** (需要 Schema Migration) |
| **Semantic Change** | 字段值同但语义不同 (e.g., 编码 Profile Main→High) | 紫色边框 | **必阻断 Apply** (需要重新 QC) |

⛔ **Structure Change 和 Semantic Change 不允许跳过 Apply。** 必须显式确认 + ChangeSet。

## 2.6 阻断式 Diff (Critical 字段)

有些字段改动不允许 Apply (无论 Desired 还是 Effective):

| 字段类型 | 例子 | 阻断原因 |
|---|---|---|
| **Schema 字段** | Profile 添加/删除字段 | 数据迁移未做 |
| **Identity 字段** | Channel ID / Profile Bundle ID | 引用关系会断 |
| **Capability 关键字段** | Video Codec 改变 (H264→HEVC) | 需要重新 QC + 重新 Capability Contract |
| **Timebase 字段** | Frame Rate 改变 (25→30) | SignalContract 不兼容 |
| **Security 字段** | Multicast SSM → ASM | 违反 Network Source Security 8 字段 |

⛔ **Critical 字段改动不弹 Impact Preview, 直接弹 "BLOCKED" Modal**, 必须人工 Override (L3) 才能继续。

```yaml
  - id: action.retry.selected
    title: "Retry Selected Job"
    shortcut: "R"
    danger_level: L1
    execute_inline: true
    requires_selection: job
    endpoint: POST /api/v1/jobs/{job_id}/retry

  - id: action.take
    title: "Take (切播)"
    shortcut: "T"
    danger_level: L2
    execute_inline: false       # L2 不允许直接执行
    target: /broadcast/cd-01/workspace?action=take
    requires_context: channel_id

  - id: action.failover
    title: "Manual Failover"
    shortcut: "F"
    danger_level: L2
    execute_inline: false
    target: /broadcast/cd-01/workspace?action=failover
    requires_context: channel_id
```

⛔ **L3 动作 (Delete) 不在 Palette 注册。** 必须从对象详情页点 Delete 按钮 → L3 确认流程。

### 3.2.4 Context-Bound Commands (0.5F F5 焊死)

命令必须携带 **Context** (surface_id / object_type / object_id / channel_id / session_id); **无上下文的模糊命令不显示** (如裸 "Retry"):

```yaml
# 上下文动作示例 (command_schema 增加 context)
context_commands:
  - id: ctx.source.verify
    title: "Verify source"
    context: {surface_id: E-40, object_type: SOURCE, object_id: UDP-MULTICAST-001}
    target: /engineering/e-42?source=UDP-MULTICAST-001
  - id: ctx.channel.take
    title: "Take CH01"
    context: {surface_id: CD-01-WS, object_type: CHANNEL, channel_id: CH01}
    danger_level: L2
    target: /broadcast/cd-01/workspace?ch=CH01&action=take
```

- **E-40 上下文动作**: Verify source · Open Test Bench (E-42) · Open Network Path (E-41) · Assign Primary。
- **CD-01 上下文动作**: Take (显示 PGM/PVW/Effective Mode/Readiness) · Open Audio · Open Output · Open Health · Failover。
- ⛔ 否则 Command Palette 会成为危险操作的「全局快捷键入口」而非广播控制台。

## 3.3 命令注册机制

### 3.3.1 注册表 (Command Registry)

```yaml
# command_registry.yaml (VBMF 后端加载, Phase 1 实施)
version: 1
commands:
  - id: nav.broadcast.dashboard
    type: navigate
    title: "Go to Dashboard"
    shortcut: "G D"
    icon: "📊"
    target: /broadcast/dashboard
    domain: BROADCAST
    roles: [operator, director, engineer, admin]   # RBAC

  - id: nav.admin.users
    type: navigate
    title: "Go to Users"
    shortcut: "G U"
    icon: "👥"
    target: /admin/users
    domain: ADMIN
    roles: [admin]                                  # 仅 admin

  # ... 全部命令
```

### 3.3.2 加载时机

| 时机 | 加载内容 |
|---|---|
| **登录时** | Static 命令 (从 command_registry.yaml 加载到前端) |
| **每次路由切换** | Dynamic 命令 (按当前 page context 加载) |
| **每次搜索 keystroke** | Search 结果 (从 query_endpoint 实时查) |

### 3.3.3 RBAC 集成

命令按角色过滤:

- **Operator**: 可见 Navigate (BROADCAST 域) + Search + L1 Action
- **Director**: 同 Operator + Bundle 操作
- **Engineer**: 全部 Navigate + 全部 Search + L1/L2 Action (无 L3)
- **SRE**: 同 Engineer + Incident 操作
- **Admin**: 全部 + A-51~55 + L3 Action

⛔ **Palette 不显示用户无权限的命令, 不显示"灰掉但可点"。** 无权限即不出现。

## 3.4 危险级 (L1/L2/L3) 处理

| 危险级 | Palette 行为 | 详情页行为 |
|---|---|---|
| **L1** (Safe) | 直接执行 + Toast 反馈 | 直接执行 + Toast |
| **L2** (Caution) | 跳转到对象详情页 + 自动打开确认 Drawer | 弹 Modal 倒计时 (3s) |
| **L3** (Dangerous) | 不在 Palette 注册 | 弹 Modal + 二次输入确认 (e.g., 输入对象 ID) |

例:

```text
用户: Ctrl+K → 输入 "Take" → 显示 L2 项
点击: 跳转 /broadcast/cd-01/workspace?ch=CH01&action=take
CD-01 Workspace 自动打开 TAKE 确认 Drawer
用户: 3s 倒计时 → [CONFIRM TAKE] → 切播
```

⛔ **Palette 不允许"灰掉但可点"。** 无权限命令彻底不出现, L2/L3 命令明确显示跳转目标。

## 3.5 Fuzzy 搜索

支持 fuzzy 匹配 (字符顺序匹配, 不要求连续):

```text
输入: "ch01"
匹配:
  · "CH01 新闻综合"     (完全)
  · "新闻综合频道01"     (部分)
  · "Channel 01"        (字符顺序)

输入: "udpmulti"
匹配:
  · "UDP-MULTICAST-001" (完全)
  · "UDP_Multicast_002" (部分)
```

算法: [Fuse.js](https://fusejs.io/) 或 [FZF](https://github.com/jhawthorn/fzy) (Phase 4 实施时选)。

## 3.6 Recent + Frequent

Palette 顶部显示:
- **Recent** (最近 5 个): 关闭后下次打开仍可见
- **Frequent** (最常 5 个): 按使用频次排序

存储: localStorage (per user, per device)。

⛔ **不同用户登录, Recent / Frequent 完全独立。** Admin 看不到 Operator 的历史。

## 3.7 6 状态

| 状态 | 触发 | UI |
|---|---|---|
| **EMPTY** | 刚打开, 无 query | 显示 Recent + Frequent + Categories |
| **TYPING** | 有 query, 搜索中 | 实时显示结果 (debounce 200ms) |
| **RESULTS** | 搜索有结果 | 分组显示 (Channels / Sources / Profiles / Actions) |
| **NO_RESULTS** | query 无匹配 | "No matches for 'xxx'" + 提示检查拼写 |
| **LOADING** | 搜索请求中 | Skeleton + 之前结果 (sticky) |
| **ERROR** | 后端错误 | "Search failed, retry?" + 错误详情 |

## 4.3 与 §24 Used By 集成
